# Audio-based Emotion Detection

A deep-learning project that classifies the emotion in a speech audio clip, comparing two
approaches:

- **`cnn_from_scratch.ipynb`** — a convolutional neural network trained from scratch on the audio
  features.
- **`transfer_learning.ipynb`** — a model built on a pretrained network (transfer learning), for
  comparison.

- **Stack:** Python, Keras/TensorFlow, NumPy (Jupyter)
- **Course:** Neural Networks — Informatics Engineering (AI), AIU.
