# Mental Health Analysis

A machine-learning classification project predicting the likelihood that an individual has
received psychological treatment, based on survey responses — aimed at supporting early detection
and reducing stigma around mental health.

- **Task:** classification (received treatment / not)
- **Data:** "Mental Health Dataset" from Kaggle (Bhavik Jikadara)
- **Work:** data cleaning, exploratory data analysis, feature preparation, and training and
  evaluating classification models
- **Stack:** Python, pandas, NumPy, scikit-learn (Jupyter)
- **Course:** Machine Learning — Informatics Engineering (AI), AIU. Team project.

`mental_health_analysis.ipynb` — the notebook · `project_report.pdf` — the write-up.
