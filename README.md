# Machine Learning Projects

Two applied ML / deep-learning projects from my Informatics Engineering (Artificial Intelligence)
degree at AIU.

## [Mental Health Analysis](Mental-Health-Analysis)
Classification predicting the likelihood that a person has received psychological treatment, from
survey data — data cleaning, exploratory analysis, and model training/evaluation in Python
(pandas, NumPy, scikit-learn). Dataset: Mental Health Dataset (Kaggle). Team project.

## [Audio-based Emotion Detection](Audio-Emotion-Detection)
Detecting emotion from speech audio, comparing two approaches: a convolutional neural network
built from scratch, and a transfer-learning model using a pretrained network (Python,
Keras/TensorFlow).
