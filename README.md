# Machine Learning Projects

Two applied ML/deep-learning projects from my Informatics Engineering (Artificial Intelligence) degree at AIU.

## [Mental Health Analysis](./Mental-Health-Analysis)
Classification predicting the likelihood that a person has received psychological treatment, from survey data — data cleaning, exploratory analysis, and model training/evaluation in Python (pandas, NumPy, scikit-learn). Dataset: Mental Health Dataset (Kaggle). Team project.

## [Audio-based Emotion Detection](./Audio-Emotion-Detection)
Comparing two approaches to 7-class speech emotion classification on a ~13K-sample dataset (HuggingFace Emotion-audio): a CNN trained from scratch and a fine-tuned wav2vec2 (facebook/wav2vec2-large-xlsr-53) transfer-learning model. The from-scratch model reached roughly 61% test accuracy, matching the pretrained baseline.
